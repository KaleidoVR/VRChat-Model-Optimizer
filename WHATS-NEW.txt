1.0.36
Texture importer on/off options are Enable, Disable, or neither, with Current and New. Neither leaves each listed texture as-is.
Special on/off options use the same layout. Enable can turn lights, cameras, stereo, and blend-shape import back on.
Apply only shows the Special warning when a Special write is not at its default. Leaving Set compression, mesh compression, Humanoid, Recalculate bounds, and crunch at Disable does not prompt.
Opening the tool once turns Set compression off if an older install had left it on, so listed textures keep the author's format unless you Enable it.
Dry Run / Apply log lists the chosen writes, then each texture as Old -> New.
