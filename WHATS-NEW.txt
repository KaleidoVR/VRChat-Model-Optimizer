What's new in 1.0.39

On Upload no longer bakes leftover blend-shape weights into the face. Unused shapes drop only at zero weight. Blink / wink / squint stay, and weights are restored by name after a strip.
Merge same-ratio blend shapes is off by default.
The two tab rows use the same four-column widths.
Reopen the tool once so existing projects pick up the new default.
